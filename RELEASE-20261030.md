# Windows installer build — 30 October 2026

Both local standalone installers in `00 - INSTALLATEURS MIO` have been rebuilt from the latest anonymous App clean source. This supersedes the earlier source-port note that EXEs were still old. The two FR/EN manuals describe the current features, generic defaults and setup steps.

Each EXE is about 3.47 GB and contains 324 ZIP entries. No payload folder is needed beside it. The graphic installer includes the Mio artwork/icon and the graphical uninstaller with confirmation. External applications and LLM weights are not bundled; their connections use the generic source defaults, without the old private test paths. API keys and models are blank and providers disabled. Initial facts and enrolled voice references are empty.

## Checks performed

- Three existing settings and process-lifecycle unit tests passed.
- Native EXE integrity verification and native extraction passed for both editions in dedicated folders with spaces in their names.
- Every extracted file matched the intended current source/resource bytes or the explicit language configuration. ZIP CRC checks and final distribution copy SHA-256 checks passed.
- Python/JSON parsing and known private-name/account-path/key pattern checks passed for application content. Public model vocabularies and vendor assets were treated as unmodified third-party resources.
- Imports, all settings pages, routing commands and portable resource paths passed checks against both extracted editions. Voice-enabled/disabled runtime environment construction passed.
- The native inspection mode refused a nonempty folder and rejected an EXE stub without its embedded archive. Packaged PowerShell syntax passed. Artwork bytes match the canonical Mio branding asset.

`00 - INSTALLATEURS MIO/SHA256SUMS.txt` identifies the final files. `BUILD-VERIFICATION.json` records the package checks.
