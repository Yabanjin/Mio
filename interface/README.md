# Mio interface

Double-click **Launch Mio.vbs** to open Mio on Windows after setting up the Python environment.

- **Customize** edits prompts and settings.
- **Start** loads the services and starts the chat.
- **Reload to apply changes** saves settings and restarts the session.
- Close the window with **X** to stop the session.

The launcher, startup script and interface code are in this folder. Keep it inside the complete Mio project: shared settings, services and dependencies live in the parent directory.

See [the user guide](../USER-GUIDE.txt) for installation details.
